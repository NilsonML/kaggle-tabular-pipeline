# Kaggle Tabular Pipeline

Универсальный пайплайн для табличных соревнований Kaggle: от трёх CSV-файлов до готового сабмита одной командой.

**Что умеет**
- Сам определяет тип задачи (бинарная / мультиклассовая классификация / регрессия), колонки `id` и `target`
- Обрабатывает категориальные признаки нативно в каждой модели
- Обучает LightGBM, CatBoost и XGBoost на K-fold кросс-валидации с early stopping
- Сохраняет out-of-fold предсказания и подбирает веса бленда моделей по OOF-метрике
- Собирает сабмит под формат соревнования: вероятности, метки, MAP@3 (top-3 классов), RMSLE
- Метрики: `auc`, `logloss`, `accuracy`, `f1_macro`, `map3`, `rmse`, `mae`, `rmsle`

## Быстрый старт

```bash
pip install -r requirements.txt

# скачать данные соревнования (нужен свой токен Kaggle, см. ниже)
kaggle competitions download -c <slug-соревнования> -p data
unzip data/*.zip -d data

# указать метрику соревнования в config.yaml, затем:
python run.py --config config.yaml

# быстрая проверка: 3 фолда, одна модель
python run.py --folds 3 --models lgbm
```

Результаты появляются в `outputs/<дата_время>/`:

| Файл | Что внутри |
|---|---|
| `submission_blend.csv` | сабмит бленда — его и отправляй |
| `submission_<model>.csv` | сабмиты отдельных моделей |
| `cv_report.json` | скоры по фолдам, OOF-метрика, веса бленда |
| `oof_<model>.npy`, `test_<model>.npy` | предсказания для стекинга и анализа |
| `importance_<model>.csv` | важность признаков |

**Токен Kaggle:** на kaggle.com → Settings → API → Create New Token, положи `kaggle.json` в `~/.kaggle/` (на Windows — `C:\Users\<имя>\.kaggle\`). Токен не коммить в репозиторий.

## Как устроено

```
run.py            точка входа, читает config.yaml
src/data.py       загрузка, определение задачи, подготовка категориальных признаков
src/models.py     единый интерфейс fit/predict для LightGBM, CatBoost, XGBoost
src/train.py      K-fold CV, подбор весов бленда (Nelder–Mead по OOF), сборка сабмита
src/metrics.py    метрики и правила формата предсказаний
```

Ключевые решения:
- **Стратифицированный K-fold** для классификации, чтобы доля классов в фолдах совпадала.
- **Оценка по OOF**, а не по одному валидационному сплиту — меньше переобучения под публичный лидерборд.
- **Бленд не хуже лучшей модели**: если оптимизатор весов застрял, берётся лучшая одиночная модель.
- **RMSLE** обучается на `log1p(target)`, предсказания возвращаются через `expm1`.
